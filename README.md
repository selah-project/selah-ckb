# تەناخ — وەرگێڕانی کوردیی سۆرانی (selah-ckb)

ئەمە وەرگێڕانی کوردیی سۆرانیی نووسراوەکانی پیرۆزی عیبرییە (تەناخ). هەر
ئایەتێک لە پەڕگەی خۆیدایە، و هەر تۆکنێک بە وشەی عیبریی خۆیەوە
بەستراوەتەوە.

**نووسین: ئەلفوبێی عەرەبی-فارسی، لە ڕاستەوە بۆ چەپ.** زمانەکە کوردیی
سۆرانیی نووسراوی ستانداردە. ڕ · ڵ · ڤ · ۆ · ێ · ە پیتی زیندووی
سۆرانین.

## عیبری — پێش هەموو شت

ئەم وەرگێڕانە بۆ ئەوە هەیە کە تۆ بەرەو عیبرییەکە ببات — نەک جێی
بگرێتەوە. ئەوەی هەمیشە دەخوێندرێتەوە عیبرییەکەیە: پیتەکانی، دەنگەکانی،
نیشانەکانی. دەقی سۆرانی پەنجەرەیە، نەک دیوار. لە هەر شوێنێک جیاواز بن،
ڕاستییەکە لای عیبرییەکەیە.

## شێوەی پەڕگەکان

```
<کتێب>/<باب>/<ئایەت>.json
```

ناوی کتێبەکان لە بوخچەکاندا بە ئینگلیزی نووسراون: `genesis/1/1.json`،
`psalms/33/12.json`.

هەر پەڕگەیەک:

```json
{
  "translation": "ئایەتەکە بە تەواوی دەخوێندرێتەوە",
  "tokens": [{"surface": "وشەی عیبری", "gloss": "گلۆسی سۆرانی"}]
}
```

`surface` — **ڕووەکە**، تۆماری عیبری. هی ئێمە نییە بینووسینەوە؛ لە دەقی
بنەڕەتەوە دێت و ناگۆڕدرێت.

`gloss` — **گلۆس**، واتای سۆرانیی هەمان یەک تۆکنی عیبری. ژمارەی گلۆسەکان
یەکسانە لەگەڵ ژمارەی وشەکانی عیبری. هەموو کات.

`translation` — **ڕەوانەکە**: ئایەتەکە یەک پارچە لە شوێنی خۆیدا، وا کە
بە دەنگ بخوێندرێتەوە.

`marks` — تەنها لەسەر تۆکنی ⟨את⟩: ئەو وشەی سۆرانی کە نیشانەکە ئاماژەی
بۆ دەکات.

## ⟨ ⟩ چی دەگەیەنێت

کەوانەی گۆشەدار بۆ دوو شتی جیاواز بەکاردێت، و جیاکردنەوەیان گرنگە.

**١ · ⟨את⟩ — نیشانەی عیبری کە وەرناگێڕدرێت.** لە عیبریدا אֵת وشەیەکی
بچووکە کە پێش ئەو شتە دەوەستێت کە کردارەکە لەسەری دەڕوات. سۆرانی وشەی
هاوتای نییە، و زۆربەی وەرگێڕانەکان بێدەنگ بەجێی دەهێڵن. ئێمە
دەیپارێزین، وەک خۆی نووسراو — ئەو بەشێکی پێکهاتەی عیبرییەکەیە. هەڵەی
چاپ نییە؛ وشەیەکە کە لە دەقەکەدا هەیە. نیشانەکە خێزانێکە: את هەندێک جار
بە پاشگرەوە دێت (ואת، אתו، אתם، מאת) — هەموویان هی هەمان خێزانن.

**٢ · ⟨وشە⟩ — سۆرانییەک کە لە عیبرییەکەدا نییە.** لە هەر شوێنێک ڕستەی
سۆرانی وشەیەک بوێت کە عیبری نەینووسیوە بۆ ئەوەی ڕابوەستێت، ئەو وشە
دەخرێتە نێوان کەوانەکان. کەوانەکان دەڵێن: *ئەم وشە وەرگێڕ زیادی کردووە؛
لە عیبرییەکەدا نییە.*

**لە ناو کەوانەدا زمانی بێگانە نییە.** یان سۆرانییە یان نیشانەی عیبری —
سێیەم نییە. گلۆسێک کە تەواو لە ناو کەوانەدایە هەڵەیە: هەر ڕیزێک وشەیەکی
عیبری لە پشتەوەیە. تاکە جیاوازی نیشانەکە خۆیەتی.

## ناوەکە

ناوەکە **وەرناگێڕدرێت، بە دەنگ دەنووسرێت**.

| عیبری | لێرە | ئەوەی ڕەتمان کردووە |
|---|---|---|
| יהוה | **یاهوە** | خودا · خواوەند · پەروەردگار · یەهۆوا · یەهۆڤا · ئەڵڵا · ڕەب |
| אלהים | **ئێلۆهیم** | خودا لە جێی ناوەکەدا |
| אל | **ئێل** | خودا وەک نازناو |
| אל שדי | **ئێل شادای** | خودای توانادار بە تەنها |
| אדני | **ئادۆنای** | خواوەند · پەروەردگار |
| יה | **یاه** | — |
| צבאות | **سەڤائۆت** | ی سوپاکان · ی لەشکرەکان |
| אהיה אשר אהיה | **ئێهیێ ئەشێر ئێهیێ** | من ئەوم کە هەم |

**خواوەند و پەروەردگار ماوەیەکی دوورودرێژە لە کتێبی پیرۆزی سۆرانیدا
دەوەستن.** لەگەڵ ئەوەشدا لێرە نین. ئەوانە **نازناون**؛ יהוה **ناوە**.
یەهۆوا شێوەیەکی تێکەڵە. لە هەر شوێنێک دەقەکە יהוה بڵێت، هەرسێکیان
ناوەکە دادەپۆشن. ئەمە نایڵێت سۆرانیی خراپن — دەڵێت ئەوان *لە جێی
ناوەکەدا* دەوەستن، نەک خودی ناوەکە. ئەوەی نەریتی بوێت لە وەرگێڕانەکانی
دیکەی سۆرانیدا دەیدۆزێتەوە. لێرە ئەوەی نووسراوە دەوەستێت.

**ئیزافە ڕێزمانە.** ــی ی ئیزافە لەسەر ناو ڕەوایە (وشەی یاهوە، کوڕی
داود) — ئەوە ڕێزمانی ئاسایی سۆرانییە و بنەمای ناوەکە ناشکێنێت. ئەوەی
ڕەوا نییە شکاندنی بنەماکەیە، یان گۆڕینی پیتێکی، یان دانانی ئامرازی
ناسراو بەسەریدا (یاهوەکە). بانگکردن بە وشەی جیای **ئەی** دەکرێت: ئەی
یاهوە.

## خودا و گەورەی ئاسایی ڕەوان

لە هەر شوێنێک عیبری باسی خوداکانی نەتەوەکان، یان گەورەیەکی مرۆڤ بکات،
**خودا**، **خوداکان**، **گەورە** بە ڕەوایی دەوەستن — ئەوە داپۆشینی
ناوەکە نییە، وەرگێڕانە. **تۆکنی عیبری بڕیار دەدات، نەک وشەی سۆرانی
بەخۆی.** لە دەرچوون ٢٠:٣ (אלהים אחרים) **خوداکانی دیکە** دەوەستن، و
لەوێ ئەوە ڕاستە.

## وشە نیشانکراوەکان

- **حەسەد** (חֶסֶד) — خۆشەویستیی پەیمان کە نابڕێت. نەک تەنها «بەزەیی»،
  نەک تەنها «میهرەبانی». یەک وشەی سۆرانی نییە کە هەڵیبگرێت.
- **شێئۆل** (שְׁאוֹל) — شوێنی مردووەکان، وەک عیبرییەکە دەڵێت. نەک
  «دۆزەخ»، نەک «جەهەننەم».
- **ماشیاح** (מָשִׁיחַ) — **چەورکراو** — لە ئاستی تەناخدا هەرگیز
  «مەسیح» نییە.
- **تۆرا** (תּוֹרָה) — فێرکردن، ڕێنمایی. **ברית** — **پەیمان**.
  **שבת** — **شابات**، ڕۆژی حەوتەم. **משכן** — **میشکان**.
- **نەفەش**، **ڕوواح**، **کاڤۆد** — بەپێی شوێنی خۆیان (گیان یان ژیان؛
  ڕۆح یان با؛ شکۆ یان قورسایی) — بە یەک وشە نەبەستراون.

ناوی کەسان و شوێنان شێوەی عیبری دەگرن: **ئاڤراهام**، **مۆشە**،
**یەهۆشوعا**، **شائوول**، **پەرعۆ**، **میتسرایم**، **یەروشالایم**.

## ئایەت لە ڕووناکیی خۆیدا

هەر ئایەتێک ئەوە دەڵێت کە لە شوێنی خۆیدا دەیڵێت — ئێمە لە سەر باوەڕی
عیبری بە تاکبوونی ئێلۆهیم دەیخوێنینەوە (دووبارەکردنەوەی یاسا ٦:٤).
فێرکردنی دواتر بەرەو دواوە ڕانەکێشراوە؛ کۆتایی چیرۆکەکە لە سەرەتایدا
ناخوێندرێتەوە. وەرگێڕ ئەوە دەدات کە نووسراوە — نە زیاتر، نە کەمتر.
